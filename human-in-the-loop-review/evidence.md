# 机制、来源与验证范围

这些说明根据本轮对私有工作副本的静态检查重新撰写。公开包不包含私有源码，阅读案例无需访问私有链接。本表是检查说明，外部读者无法据此独立复跑原系统。

| 业务机制 | 本轮核对位置 | 能确认的范围 |
|---|---|---|
| 必须复核阻断自动采用 | review_case_store 的采用检查 | 开放 must_review 工单参与自动采用阻断 |
| 人工最终锁定 | 同模块的锁定与采用状态推进 | active锁阻止自动替换及撤销被锁定采用记录 |
| 尝试与任务状态 | pipeline_task_manager、原仓库工程约束 | 任务状态与尝试、采用结果分别维护；重试保留历史 |
| 导出准备 | result_derivation_service | 结果推导与导出阻断分开检查 |
| 422处理 | TeamManage.loadCompetitionConfig | 先获取当前赛事，再传入真实赛事ID请求维度 |

本轮完成静态文档与代码片段核对。端到端运行、浏览器交互、模型调用与真实效果均未在本批重新验收。合成卡片说明业务情形，不替代运行证据。
