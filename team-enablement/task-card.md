# 把一个岗位任务交给 AI 前，先填这张卡

从报告、数据分析等日常任务中选一个真实且范围清楚的例子。第一次使用时保留人工核对，记录哪里需要补充说明。

| 要确认的事 | 填写提示 |
|---|---|
| 谁会用结果 | 给哪个岗位看？看完要做什么？ |
| 最后交付什么 | 表格、报告还是操作步骤？长度、字段、格式有什么要求？ |
| 有哪些输入 | 哪几份文件、哪些字段、哪个时间范围？材料是否允许放入所用工具？ |
| 哪些口径不能变 | 汇总方式、分母、单位、筛选条件、不可自行补全的信息 |
| 怎样执行 | 先整理输入，再计算或生成，最后检查；每步保存什么？ |
| 怎样判断能用 | 核对源数据、关键数值、缺失信息、引用和格式；谁确认？ |
| 第一次哪里卡住了 | 输入问题、描述不清、工具限制还是结果错误？下一次调整什么？ |

可以按这个顺序描述任务：

> 我需要为【使用者】完成【交付物】。输入是【材料与字段】，范围为【时间／对象】。请遵守【口径和限制】，先完成【第一步】，再完成【第二步】。缺少信息时请列出，不要补造。最终按【格式】输出，并列出需要我核对的内容。

这张卡是从培训经验中重新整理的模板，尚未单独统计使用效果。[返回培训案例](README.md)
